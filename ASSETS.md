# Euro Games Assets

**Art direction:** A premium, mobile-friendly Euro games dashboard using deep emerald-green and near-black surfaces, warm gold for active controls and multipliers, and clean high-contrast typography. The first release uses a precise 2D Aviator runway chart, a simple gold aircraft, compact wallet cards, and restrained line-icon game tiles. It avoids real gambling brands, currency imagery, crowded casino decoration, and visual effects that would obscure state or controls.
